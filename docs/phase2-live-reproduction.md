# Phase II live-reproduction plan

Generated by `uv run python src/phase2/verify_phase2.py plan --markdown docs/phase2-live-reproduction.md`. Nothing in this file has been executed.
The recorded outcome of the live runs (rows, errors, tokens, estimated cost, result-file hashes) is in `data/results/phase2/phase2_manifest.json` under `live_stress_results`.

Known limitations (also in the manifest under `known_limitations`):
- Cascade and cost-quality results use the Phase I matched population only (2,180 matched requests plus the Phase I cost-quality workloads).
- The 5,189 Phase II stress predictions do NOT have reference-LLM counterparts; no reference-LLM calls were made for them and none are implied by any cascade or cost-quality figure.
- Rules coverage is 0 in every cascade result because no rules baseline is implemented (src/clients/rules_client.py is empty).
- Cost figures are estimates (recorded tokens x src/evaluation/pricing.py; the Jev rates are owner notes, unverified), not billing; cascade latency is a simulated sequential sum, not a measured cascade.

- Jev calls to reproduce every Phase II live experiment: **5189**
- Optional reference-LLM calls (same datasets): **5189**
- Estimated cost: Jev $0.1142, reference LLM $1.1342
- Cost basis: mean recorded Phase I tokens/call x src/evaluation/pricing.py rates (jev-1.13.0: owner notes, unverified; gpt-4o-mini: OpenAI page read 2026-09-23). ESTIMATES; context-heavy datasets cost more.
- Safety: each `run` refuses unless --approve-calls equals the exact expected call count; dry runs (`report`) construct no client

Each experiment: run the dry run first (no API calls), then the live command (MAKES API CALLS), then analyze (offline).
